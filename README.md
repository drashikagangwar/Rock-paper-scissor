# Rock-paper-scissor

A simple and interactive Rock Paper Scissors game built to demonstrate basic programming concepts such as user input, conditional statements, randomization, and game logic.

# 📌 Features

- 🎮 Interactive gameplay
- 🤖 Play against the computer
- 🎲 Random computer choices
- 🏆 Displays the winner after each round
- 🔄 Option to play multiple rounds
- 💻 Simple and beginner-friendly implementation

# 🛠️ Technologies Used

- Programming Language: Python
- Concepts: Conditional Statements, Loops, Functions, Random Module, User Input

# 🚀 How to Run

1. Clone the repository:
   
   git clone <repository-url>

2. Navigate to the project directory:
   
   cd rock-paper-scissors

3. Run the program:
   
   python rock_paper_scissors.py

# 🎯 How to Play

Choose one of the following options:

- 🪨 Rock
- 📄 Paper
- ✂️ Scissors

The computer will randomly select its choice, and the program will determine the winner based on the standard rules:

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
